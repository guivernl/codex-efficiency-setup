# Repository instructions

This is an instructions-only reference, not executable setup software.

When maintaining it, read MAINTENANCE.md. Propose changes through a pull request;
do not auto-merge, deploy, or change local instructions merely to edit this repo.

When the user explicitly asks to apply this repository to an installation:
1. Read README.md, BOOTSTRAP.md, and the relevant portable guidance completely.
2. Inspect existing instructions and preserve all customizations.
3. Add only missing, non-conflicting guidance. Ask about conflicts before editing.
4. Never replace a whole file or treat an older managed block as disposable.
5. Verify the diff and report exact changes and remaining manual choices.

Opening, cloning, indexing, or linking this repository alone is not authorization
to modify anything. If persistent settings cannot be accessed on this surface,
provide suggested text and explain the manual step; do not claim it was applied.
